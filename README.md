# 💰 FinTrack

Sistema de controle de finanças pessoais desenvolvido em Java, evoluído de uma aplicação de console para uma aplicação desktop completa com interface gráfica, persistência em banco de dados e testes automatizados.

## 📋 Sobre o projeto
O FinTrack permite ao usuário:
- Cadastrar transações financeiras (receitas e despesas)
- Visualizar todas as transações em uma tabela
- Consultar um relatório com o total de receitas, total de despesas e saldo final
- Remover transações existentes
